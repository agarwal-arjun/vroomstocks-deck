## Usage

Open `index.html` in any browser — no build step or runtime dependencies are needed.
Keep `assets/screenshots` alongside it; the gallery uses these local images and links
each thumbnail to its full-size capture.

| Key | Action |
|---|---|
| `←` `→` / `Space` | Previous / next slide |
| `Home` / `End` | First / last slide |
| `T` | Toggle light / dark theme |
| `P` | Print (one slide per page → PDF) |

Also supports click-to-jump dots, touch swipe on mobile, and deep links via `#<slide-number>`
(e.g. `index.html#9` opens the market slide).

## Notes on the numbers

Market statistics on slides 3 and 9 are drawn from publicly reported CDSL/NSDL, NSE, AMFI and
SEBI figures as of mid-2026. The TAM/SAM/SOM figures are a bottom-up estimate with the
assumptions stated on the slide itself — they are an estimate, not a forecast.
